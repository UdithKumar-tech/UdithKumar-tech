## 🚀 Selected Projects

### 🌧️ Meghova — AI-Powered Rainfall Forecast Correction

**Python · XGBoost · FastAPI · React · Leaflet**

A team project developed for Smart India Hackathon 2026, focused on improving numerical weather prediction forecasts using machine learning.

The system combines rainfall regime classification, specialized correction models, backend inference, and an interactive dashboard.

**Highlights**
- Integrates an XGBoost regime classifier and five rainfall correction models.
- Connects machine learning inference to a React frontend through FastAPI.
- Visualizes rainfall predictions, geographic data, and verification metrics.
- Includes time-based model evaluation and documents performance limitations.

The project reported a 74.31% RMSE reduction on its 2025 evaluation, although a smaller 2026 verification sample did not reproduce that improvement.

[Explore Meghova](https://github.com/UdithKumar-tech/Meghova)

### 🗺️ CityWise — Smart Tourism Discovery Platform

**React · TypeScript · Tailwind CSS · Leaflet**

A tourism-focused application developed during TechNovate 2.0, where our team won first place in the department-level hackathon.

CityWise explores how technology can make travel planning more accessible and personalized.

**Highlights**
- Helps users discover attractions and lesser-known destinations.
- Supports itinerary planning around available time and budget.
- Integrates interactive maps and route visualization.
- Explores local food recommendations and ways to reduce communication barriers.

### 🛰️ GARUDA Sentinel — Satellite Intelligence & Security

**Python · FastAPI · Machine Learning · React · Cesium**

A space and defence technology prototype exploring satellite telemetry monitoring, anomaly detection, and navigation security.

**Key areas explored**
- Telemetry ingestion and anomaly detection.
- GNSS spoofing simulation and detection.
- Satellite tracking and orbital visualization.
- Secure API design and encrypted communication.

The project combines real data processing with explicitly identified simulation components.
